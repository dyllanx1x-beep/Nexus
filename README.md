# NEXUS PRIME

**An experimental modular software project exploring symbolic inference, structured memory, evaluation and local AI-assisted workflows.**

[Português](#português) · [English](#english)

## Português

NEXUS PRIME é um projeto experimental que investiga uma arquitetura modular combinando mecanismos simbólicos, memória estruturada, avaliação de resultados e ferramentas auxiliares de execução. Modelos locais, como os executados pelo Ollama, podem atuar como componentes opcionais; não são prova de capacidades nativas do núcleo.

Este repositório público contém documentação e evidências selecionadas, não uma distribuição executável.

**Estado:** documentação pública em preparação. **Versão documental de referência:** 1.14.2, identificada no pacote auditado em 04/11/2026. **Distribuição pública:** ainda não aprovada.

### Áreas técnicas
- RNA / inferência simbólica e relações estruturadas.
- Memória persistente e recuperação contextual.
- Avaliação por critérios explícitos.
- Worker para processamento auxiliar por fila.
- Integrações opcionais com serviços e modelos locais.

Consulte [Arquitetura](docs/ARCHITECTURE.md), [Evidências](docs/EVIDENCE.md) e [Roteiro](docs/ROADMAP.md).

## English

NEXUS PRIME is an experimental project exploring a modular architecture combining symbolic mechanisms, structured memory, result evaluation and auxiliary execution tools. Local models, including those served by Ollama, may be optional components; they are not proof of native core capabilities.

This public repository contains documentation and selected evidence, not an executable distribution.

**Status:** public documentation in preparation. **Documentation reference:** 1.14.2, identified in the package audited on 2026-11-04. **Public distribution:** not yet approved.

### Technical areas
- RNA / symbolic inference and structured relations.
- Persistent memory and contextual retrieval.
- Explicit evaluation criteria.
- Queue-based auxiliary Worker processing.
- Optional integrations with local services and models.

See [Architecture](docs/ARCHITECTURE.md), [Evidence](docs/EVIDENCE.md) and [Roadmap](docs/ROADMAP.md).

### Limitations and transparency
The reference-package audit found private data and development artifacts mixed into the package. The original package was not approved for direct publication. Historical results have different scopes and do not certify the complete product. We do not claim general intelligence, certified security, superiority over competitors or commercial readiness.

### Privacy
Never publish personal databases, credentials, private keys, user files, backups, private logs, development Git history or local environments. Publish only sanitized documentation and explicitly reviewed artifacts.
