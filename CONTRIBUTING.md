# Contributing / Como Contribuir

## Português
Obrigado pelo interesse no NEXUS PRIME. Descreva problemas com passos reproduzíveis, sistema operacional, versões e comandos relevantes. Use apenas dados sintéticos e logs sanitizados. Nunca envie credenciais, chaves, bancos pessoais, dados de clientes ou backups. Mudanças devem ser focadas, documentadas e acompanhadas de testes pertinentes. Componentes experimentais devem permanecer identificados como experimentais.

## English
Thank you for your interest in NEXUS PRIME. Describe issues with reproducible steps, operating system, versions and relevant commands. Use synthetic data and sanitized logs only. Never submit credentials, keys, personal databases, customer data or backups. Changes should be focused, documented and accompanied by relevant tests. Experimental components must remain clearly labeled.
