# Security Reporting / Relato de Segurança

## Português
Não publique segredos, dados pessoais, chaves, tokens, bancos de dados ou detalhes privados em issues públicas. Este repositório é atualmente um espaço de documentação e não representa uma distribuição aprovada para produção. Para relatar uma preocupação, utilize canais privados de contato do mantenedor no perfil GitHub. Use exemplos sintéticos. Não há prazo de resposta ou programa formal de recompensas anunciado.

## English
Do not post secrets, personal data, keys, tokens, databases or private details in public issues. This repository is currently a documentation space and is not an approved production distribution. To report a concern, use the maintainer's private contact channels on the GitHub profile. Use synthetic examples. No response-time commitment or formal bounty program is announced.
