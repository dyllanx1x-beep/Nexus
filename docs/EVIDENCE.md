# Evidence Register / Registro de Evidências

> Results are specific to a version and test scope. Historical results are not certification of the complete current product.

## Português

### Auditoria estática do pacote 1.14.2 — 04/11/2026
Inspeção do pacote fornecido; o original não foi modificado.
- 6.489 entradas ZIP; 5.363 arquivos efetivos; aproximadamente 250 MiB descompactados.
- 63 arquivos diretamente na pasta de testes: 47 Python e 16 JavaScript. Contagem de arquivos, não de casos.
- 169 arquivos Python principais analisados com parser AST; zero erros de sintaxe no recorte analisado.
- Foram identificados bancos de dados privados, histórico Git, backups e artefatos de desenvolvimento.
- A aplicação e os testes não foram executados nessa auditoria.
**Conclusão:** não aprovado para publicação direta. Análise sintática não comprova funcionamento.

### Alpha 0.7 — 22/10/2026
Relatório histórico registra 113 testes Python e 19 JavaScript aprovados, além de casos adicionais de relações, cadeias, conflitos, revogação, reformulação, persistência e conhecimento ausente. O relatório ressalta que isso não demonstra inteligência geral, linguagem natural irrestrita ou superioridade competitiva; não houve teste end-to-end Windows nem carga prolongada nessa rodada.

### Distribuição X / Patch 20 — 20/10/2026
Relatório de uma cópia isolada registra 84 testes Python e 19 Node aprovados (103 nessa execução). Testes de instalador/rollback não foram confirmados nessa rodada. Não foi demonstrado benchmark A/B justo de eficiência.

### Worker / IndependentEvaluator — relato de desenvolvimento
Registros do autor relatam implementação de serviços Worker e módulo IndependentEvaluator com testes concluídos. Para serem evidência pública reproduzível da versão atual, ainda precisam de logs completos, comandos, ambiente e revisão independente.

## English

### Static audit of package 1.14.2 — 2026-11-04
Inspection of the supplied package; the original was not modified.
- 6,489 ZIP entries; 5,363 effective files; approximately 250 MiB extracted.
- 63 files directly under the test directory: 47 Python and 16 JavaScript. This is a file count, not a test-case count.
- 169 main Python files inspected with the AST parser; zero syntax errors in the inspected subset.
- Private databases, Git history, backups and development artifacts were identified.
- The application and tests were not executed during this audit.
**Conclusion:** not approved for direct publication. Syntax parsing does not prove runtime behavior.

### Alpha 0.7 — 2026-10-22
A historical report records 113 passing Python tests and 19 passing JavaScript tests, plus additional cases covering relations, chains, conflicts, revocation, reformulation, persistence and missing knowledge. The report states these results do not demonstrate general intelligence, unrestricted natural language or competitive superiority; no Windows end-to-end or prolonged-load test was run in that round.

### Distribution X / Patch 20 — 2026-10-20
A report for an isolated copy records 84 passing Python tests and 19 passing Node tests (103 in that execution). Installer/rollback tests were not confirmed in that run. No fair A/B efficiency benchmark was demonstrated.

### Worker / IndependentEvaluator — development report
Author-supplied development records report implementation of Worker services and the IndependentEvaluator module, with tests reported as completed. Complete logs, commands, environment details and independent review are still needed before these can be treated as reproducible public evidence for the current version.
